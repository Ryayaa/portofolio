Tentu, berikut adalah versi yang sudah diperbarui dengan menyertakan total jam pembelajaran untuk setiap sertifikasi. Informasi ini akan memberikan gambaran yang lebih jelas mengenai dedikasi waktu yang kamu alokasikan, dan tentunya akan terlihat menarik saat ditampilkan di portofolio SvelteKit kamu.

Python & Back-End Development
Belajar Back-End Pemula dengan Python (40 Jam)
Sertifikasi ini memvalidasi kemampuan dalam membangun web service berstandar industri.

Berfokus pada pembuatan RESTful API sederhana secara mandiri menggunakan kerangka kerja Django dan Django REST Framework.

Mencakup pengujian API menggunakan Postman dan deployment langsung ke Google Cloud Platform.

Memulai Pemrograman dengan Python (60 Jam)
Sertifikasi dasar yang mengukuhkan fundamental pemrograman Python sesuai standar industri.

Meliputi penguasaan interaksi data, kontrol alur (control flow), pemrosesan array dan matriks, serta subprogram.

Mencakup penerapan Object-Oriented Programming (OOP), unit testing otomatis, dan penggunaan berbagai library populer Python.

Artificial Intelligence & Data
Belajar Machine Learning untuk Pemula (90 Jam)
Sertifikasi komprehensif untuk pengembangan proyek machine learning pada data tabular.

Mencakup pemahaman alur kerja ML, dari pengumpulan data hingga evaluasi model.

Melibatkan praktik Supervised Learning (Klasifikasi dan Regresi) serta Unsupervised Learning (Clustering).

Menerapkan optimasi model melalui Feature Engineering dan Hyperparameter Tuning.

Belajar Dasar AI (10 Jam)
Pengenalan komprehensif terhadap ekosistem Artificial Intelligence.

Membahas konsep pemanfaatan data untuk pengembangan AI.

Mencakup dasar-dasar Machine Learning dan implementasi konsep penting dalam Deep Learning.

Belajar Dasar Data Science (11 Jam)
Sertifikasi yang memvalidasi pemahaman siklus dan tahapan proses analisis data.

Mengeksplorasi penggunaan teknologi pendukung seperti SQL, NoSQL, Tableau, serta bahasa Python dan R.

Mencakup penerapan machine learning di ranah data science.

Prompt Engineering untuk Software Developer (16 Jam)
Sertifikasi yang difokuskan pada pemanfaatan Generative AI untuk pengembangan perangkat lunak.

Mendalami berbagai pola dan praktik terbaik untuk menyusun prompt yang adaptif dan efektif.

Memahami batasan dan etika dalam penggunaan AI generatif.

Cloud Computing
Belajar Dasar Google Cloud (12 Jam)
Sertifikasi yang mengacu pada standar kompetensi internasional Google untuk ekosistem cloud computing.

Meliputi arsitektur server dan jaringan menggunakan Google Compute Engine (GCE).

Mencakup manajemen storage, database, serta keamanan melalui Cloud Identity and Access management (IAM).

Menganalisis estimasi biaya (billing) untuk meningkatkan efisiensi dan nilai bisnis.

UI/UX Design
Belajar Dasar UX Design (23 Jam)
Sertifikasi desain berbasis pendekatan Design Thinking.

Memvalidasi kemampuan riset pengguna melalui pembuatan Empathy Map, User Persona, dan User Journey Map.

Mencakup pembuatan User Flow, Wireframe, hingga perancangan High-Fidelity Prototype yang interaktif.

Melibatkan pelaksanaan usability study dan dokumentasi riset untuk iterasi desain.
